# BarnixRepo

Репозиторий программ для Barnix. Их ставит `brm` — Barnix Repository
Manager, с ключами как у pacman в Arch.

## Программы

| Пакет | Что это |
|---|---|
| `gsnake` | Гусиная змейка: окно в стиле Весёлого Гуся, золотые яблоки, уровни, рекорд |
| `g2048` | 2048 с анимацией и отменой хода |
| `tetra` | Тетрис под «Коробейников», с запасом фигуры и тенью |
| `life` | Игра «Жизнь» Конвея: рисуй мышью, готовые фигуры |
| `fireworks` | Салют над ночным городом: щёлкай по небу |
| `matrix` | Зелёный дождь из «Матрицы» на весь экран |
| `gousesay` | Гусь говорит твои слова (как cowsay) |
| `sl` | Паровоз для тех, кто набрал `sl` вместо `ls` |
| `magic8` | Волшебный шар отвечает на вопросы |

Графические программы берут тему, цвет рабочего стола, громкость и язык
из настроек Весёлого Гуся (`~/.gouse.cfg`). По умолчанию они на русском,
английский включается в «Панели управления» Гуся.

## brm в Barnix

```
sudo brm -Sy                 скачать список пакетов
brm -Ss                      что есть в репозитории (brm -Ss snake - поиск)
sudo brm -S gsnake tetra     установить
gsnake                       запустить (или в Гусе: «Запустить программу...»)
brm -Q                       что установлено
sudo brm -Syu                обновить всё
sudo brm -R sl               удалить
sudo brm set-repo https://... другой репозиторий
brm -h                       все ключи
```

## Выложить на GitHub

Один раз создай на github.com пустой публичный репозиторий `BarnixRepo`
(без README и лицензии). Потом после любых изменений:

```
./publish.sh "что изменилось"
```

Скрипт соберёт программы и загрузит их. `brm` по умолчанию берёт пакеты
из `https://raw.githubusercontent.com/ArtemShamaev/BarnixRepo/main`.

## Своя программа

1. Папка `programs/ИМЯ/src/main.c` с `#define BARNIX_APP_NAME "ИМЯ.elf"`.
   Имя пакета: a-z, 0-9, `_`, `-`, до 18 символов. Оно не должно совпадать
   с командами Barnix.
2. `programs/ИМЯ/package.info`:
   ```
   version=1.0
   description=What it does
   description.ru=Что делает
   ```
3. `./build.sh` соберёт её, положит `packages/ИМЯ.elf` и обновит `index`.
   При новой версии подними `version`, и `brm -Syu` её обновит.

`common/look.h` даёт окно, кнопки, диалоги и звуки в стиле Гуся, а также
выбор языка (`L("English", "Русский")`). Пример — любая программа из
`programs/`.

Нужен Barnix BDK: в репозитории Barnix выполни `make bdk`. Сборка ищет SDK
в `~/Barnix/BDK/dist/sdk`; другой путь можно задать так: `BDK=/путь ./build.sh`.

## Формат репозитория

`index` — текстовый файл, первая строка `# Barnix repository v1`, дальше по
строке на пакет:

```
имя|версия|packages/имя.elf|размер|sha256|описание|описание.ru
```

`brm` проверяет размер и SHA-256 каждого файла перед установкой.
Подойдёт любой HTTP(S)-сервер с такими файлами.
